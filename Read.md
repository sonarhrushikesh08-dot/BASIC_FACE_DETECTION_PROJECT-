📸 Face Detection Project

This project is a real-time face detection system developed using Python and OpenCV. It uses the webcam to capture live video and detects human faces using the Haar Cascade algorithm. 🧠✨

Whenever a face is detected, the program draws a green rectangle around it in real time. 🟩👤 The video continues until the user presses the "a" key to exit. ⌨️🚪

🔧 Technologies Used

Python 🐍

OpenCV 👁️

Haar Cascade Classifier 📚
